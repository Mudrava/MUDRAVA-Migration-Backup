# Logo review, round 2

The owner selected option 03 Archive and requested vertical centering of its M.
The selected source and directory icons are updated. Other options remain as
review history. The banner will be composed separately.

1. Brand uses the M letterform from the saved MUDRAVA studio wordmark.
2. Transfer uses opposing directions to communicate migration and restore.
3. Archive combines a backup container with the studio M.
4. Link uses connected paths to communicate movement between sites.

The review board includes 48 px, 32 px and single ink variants. Editable SVG
sources and PNG renders are included. All four palettes are proposals.

Run `node render.cjs` with Sharp available through Node module resolution.
The generator reads `../studio-logo.svg` for the original M geometry.
